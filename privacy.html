Privacy Policy

RoShelf allows users to organize, save, and display voluntary Roblox game lists. This policy explains the information involved and how it is used.

1. Controller and contact

RoShelf is an independent project. For privacy questions, access, corrections, and deletion requests, contact doldiecontato@gmail.com .

2. Information processed

  • Public Roblox account identity: numeric user ID, username, display name, and avatar image URL obtained after OAuth authorization.
  • User-selected lists: game/universe and place IDs, game names, image URLs, custom categories, preference ratings from 1 to 5, custom order, featured games, privacy settings, and creation dates.
  • Authorization: short-lived OAuth access tokens are kept in the extension session. A refresh token is stored in local browser extension storage with access restricted to trusted extension contexts, allowing the sign-in session to be renewed. OAuth tokens are not stored in the game-list database.
  • Profile and game queries: when a Roblox profile is visited, the extension extracts its ID from the URL to request that user's list. Game searches are sent to Roblox services.
  • Technical records: infrastructure providers may process connection and error logs under their own policies.

3. Purposes

To identify the account allowed to edit a list; store that account's chosen ratings; show ratings to other extension users on Roblox profiles; retrieve public game metadata; and maintain service functionality and security.

4. Lists are public by default

Categories are public by default but may be marked private. Public API queries and visitors do not receive the names, games, or statistics of private categories. The authenticated owner can access and edit their own private categories. Public featured-game displays and imports from other profiles only include games in public categories.

5. Sharing and service providers

RoShelf uses Roblox OAuth, game APIs, and public profile pages, and uses Supabase for database and API hosting. Data needed for these functions travels between the extension, Roblox, and Supabase. Processing may take place outside your country. The current RoShelf code does not sell user lists to advertisers or implement advertising trackers.

6. Storage and security

Game lists are stored in an online database. The server verifies OAuth access tokens with Roblox before allowing additions or removals. RoShelf does not request Roblox passwords or read the .ROBLOSECURITY cookie. Access tokens are not exposed to scripts injected into Roblox pages. No system can guarantee absolute security.

7. Retention and deletion

Game-list records remain until removed or a deletion request is fulfilled. Authenticated users can remove games and empty categories. There is not yet a built-in option to delete the entire RoShelf account and all its data. To request full deletion or correction, contact doldiecontato@gmail.com. Ownership may need to be verified without requesting a Roblox password. Revoking OAuth authorization does not automatically delete saved game lists.

8. Your choices and rights

You can review displayed information, change categories, and remove games. To request access, correction, or full deletion of information linked to your Roblox account, contact us using the email address listed above. We may need to verify account ownership, without requiring your password.

9. Young users

RoShelf relies on Roblox's OAuth eligibility rules, currently requiring accounts aged 13+. Applicable privacy protections for minors still apply. Do not use RoShelf to publish sensitive personal details about yourself or others.

10. Updates

This policy will be updated if RoShelf's practices, processed data, or providers change, and significant changes should be communicated appropriately.

RoShelf is an independent extension and is not affiliated with, sponsored by, or endorsed by Roblox Corporation. · doldiecontato@gmail.com
