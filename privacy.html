Privacy Policy

RoShelf allows users to organize, save, and display voluntary Roblox game lists. This policy explains the information involved and how it is used.

1. Controller and contact

RoShelf is an independent project. For privacy questions, access, corrections, and deletion requests, contact [COLOQUE_SEU_EMAIL_PUBLICO_AQUI].

2. Information processed

  • Public Roblox account identity: numeric user ID, username, display name, and avatar image URL obtained after OAuth authorization.
  • User-selected lists: game/universe and place IDs, game names, icon URLs, categories, and creation dates.
  • Authorization: a short-lived OAuth access token stored in the extension's chrome.storage.session and sent to the server to authenticate changes. The current version does not store this token in the database and discards refresh tokens.
  • Profile and game queries: when a Roblox profile is visited, the extension extracts its ID from the URL to request that user's list. Game searches are sent to Roblox services.
  • Technical records: infrastructure providers may process connection and error logs under their own policies.

3. Purposes

To identify the account allowed to edit a list; store that account's chosen ratings; show ratings to other extension users on Roblox profiles; retrieve public game metadata; and maintain service functionality and security.

4. Lists are public by default

Once saved, your game ratings are public to users of RoShelf who visit your Roblox profile. Categories and game selections are not private. The current version has no setting to make an entire list private. Public lists can also be queried without authentication via the API.

5. Sharing and service providers

RoShelf uses Roblox OAuth, game APIs, and public profile pages, and uses Supabase for database and API hosting. Data needed for these functions travels between the extension, Roblox, and Supabase. Processing may take place outside your country. The current RoShelf code does not sell user lists to advertisers or implement advertising trackers.

6. Storage and security

Game lists are stored in an online database. The server verifies OAuth access tokens with Roblox before allowing additions or removals. RoShelf does not request Roblox passwords or read the .ROBLOSECURITY cookie. Access tokens are not exposed to scripts injected into Roblox pages. No system can guarantee absolute security.

7. Retention and deletion

Records remain until removed or a deletion request is fulfilled. Authenticated users can remove individual games. Version 0.10 does not yet offer automatic deletion of the entire list/account. To request full deletion or correction, contact [COLOQUE_SEU_EMAIL_PUBLICO_AQUI]. The operator should verify account ownership by suitable means without asking for a Roblox password. Revoking Roblox OAuth authorization does not automatically delete stored RoShelf lists.

8. Your choices and rights

You can inspect your displayed information, change categories, remove individual games, and request access, correction, or deletion of data linked to your ID, under applicable law. A full deletion procedure must be operational before public launch.

9. Young users

RoShelf relies on Roblox's OAuth eligibility rules, currently requiring accounts aged 13+. Applicable privacy protections for minors still apply. Do not use RoShelf to publish sensitive personal details about yourself or others.

10. Updates

This policy will be updated if RoShelf's practices, processed data, or providers change, and significant changes should be communicated appropriately.

RoShelf is an independent extension and is not affiliated with, sponsored by, or endorsed by Roblox Corporation.
